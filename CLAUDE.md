# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A static, single-page marketing site for Canvas & Co, a two-person art-print studio in Portland, OR. It is a tutorial starter project: no build step, no package manager, no tests, no linter, and not a git repository yet (`git-setup-guide.md` covers installing Git/GitHub for the later "publish to the web" step).

## Running it

`.claude/launch.json` defines a `static-site` server (`py -3 -m http.server 8000 --bind 127.0.0.1`). Start it with `preview_start` (name `static-site`) and open `http://localhost:8000`, or open `index.html` directly.

## Architecture

- `index.html` + `styles.css` are the whole site. There is no JavaScript.
- **Product data is duplicated, not generated.** `products.csv` (`name,category,price,image`) is the source of truth, but the product cards in `index.html` are hand-written markup, appearing twice: grouped into three `.collection` blocks (Landscape, Botanical, Abstract), and again in the flat `#catalog` grid (image, category `.tag` pill, name, price). When adding or changing a product, update the CSV and both cards, and keep the `images/*.svg` filename in sync.
- Card image alt text follows the pattern `"<Name>, <Category> print"`.
- `design.md` is the visual spec (palette, 1080px width, 12–14px radius cards, pill tags, whole-dollar prices). `styles.css` implements it via CSS custom properties in `:root`. The single breakpoint is `max-width: 720px`, which stacks the hero and makes grids 2-column.

## Data files (not wired into the site)

- `sales.csv`: order lines (`order_id,date,customer_name,email,category,product,quantity,unit_price,line_total`), roughly 100 rows starting in January 2026. It contains customer names and emails, so don't paste them into the site or commit them to a public repo.
- `testimonials.csv`: `date,customer_name,location,product,rating,quote`.
- `customer-favorites.md` (top 4 products by order count + matching testimonials) is generated from the latest sales/testimonials data in the "Canvas & Co Sales" Google Drive folder by the `customer-favorites` skill (`.claude/skills/customer-favorites/SKILL.md`) — re-run that skill to refresh it rather than hand-editing.
- `competitor-research.md` (3–4 real comparably-small competitors + one positioning gap, under 150 words) is generated by web research via the `competitor-research` skill (`.claude/skills/competitor-research/SKILL.md`) — re-run that skill to refresh it rather than hand-editing. The `competitor-researcher` subagent (`.claude/agents/competitor-researcher.md`, has `WebSearch`/`WebFetch`) runs this skill end-to-end.
- The `#why` "Why Canvas & Co" section on the homepage (`index.html`) is hand-written, not generated: its lead paragraph is a manual translation of the positioning gap in `competitor-research.md`, and its four product cards/testimonials are manually copied from `customer-favorites.md`'s top-4 ranking and quotes. If either source file is regenerated (new competitors, a reshuffled top 4, different quotes), the `#why` section won't update automatically — re-copy the relevant text into `index.html` by hand, the same way product data is kept in sync across `products.csv` and the two card locations.

## Brand voice (from `company.md`)

Warm, human, handmade, plain and unhurried. Say "art for people's homes", not "products" or "solutions". Studio contact details (email, address, hours) live in the footer and in `company.md`. Keep them consistent if either changes.
